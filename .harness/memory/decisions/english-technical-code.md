# English technical code convention

## Type

Decision

## Summary

Technical code and developer-facing engineering text are written in English. User-facing copy follows the future product locale, while localization keys remain English.

## Evidence

- `docs/decisions/0002-english-technical-code.md`
- `.harness/context/agent-readable-code.md`

## Consequence

Use English when creating or reviewing identifiers, paths, tests, comments, logs, APIs, database objects, migrations, and errors. Do not infer an interface language from this technical convention.
