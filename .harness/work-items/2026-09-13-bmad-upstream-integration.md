Use BMad as the upstream planning layer and pass only approved delivery contracts into the Harness downstream layer.

## Acceptance criteria

- BMad Method is installed locally for supported agent tools.

## Scope

- No product requirement, implementation feature, remote repository, or deployment is created.

## Verification

- BMad skill installation reports completion.
- Configuration and skill frontmatter validate.
- The upstream skill is synchronized to supported Harness adapters.
