# Work Item: apply selected BMad practices downstream

## Outcome

Apply five proportional BMad practices to downstream delivery: work sizing, readiness, decision records, course correction, and independent review.

## Acceptance criteria

- Harness configuration, instructions, work-item template, feature skill, PR skill, PR template, and workflows enforce the five selected practices.
- Direct low-risk work remains lightweight.
- BMad walkthrough and retrospective are explicitly deferred.

## Scope

- Harness documentation, configuration, templates, skills, memory, and adapter copies only.
- No feature code, remote repository rule, external approval, or production deployment is changed.

## Verification

- YAML and skill frontmatter validate.
- Updated source skills are synchronized to every Harness adapter.

## TDD evidence

Not applicable: this is a non-executable process change. Future features remain subject to TDD.
